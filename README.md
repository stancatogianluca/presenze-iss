# Presenze ISS v1.0
PWA per il calendario delle presenze personali, con 10 giorni mensili di smart working.

## Pubblicazione su GitHub Pages
1. Crea un nuovo repository **presenze-iss** su GitHub (preferibilmente privato; verifica le limitazioni del piano Pages).
2. Carica nella radice del repository i file di questa cartella.
3. In Settings → Pages scegli **Deploy from a branch**, branch **main**, cartella **/(root)** e salva.
4. Apri l'URL HTTPS indicato da GitHub Pages in Safari su iPhone e scegli Condividi → Aggiungi alla schermata Home.

I dati sono salvati localmente nel browser tramite localStorage, non su GitHub. Esporta regolarmente un backup JSON per evitare perdite di dati. Non è un sistema ufficiale di rilevazione presenze.
